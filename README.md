# Public Petty Cash Demo

This folder is a sanitized, fictional demo prepared for GitHub Pages. It is separate from the working app in the parent folder.

## Publish on GitHub Pages

1. Create a **public** GitHub repository, for example `francis-petty-cash-demo`.
2. Upload only the files in this folder (`index.html` and `README.md`). Do not upload the parent folder's original app or product specification.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Open the published URL shown in the Pages settings. It will look like `https://YOUR-USERNAME.github.io/francis-petty-cash-demo/`.

## Demo safety

- The page is public and has no authentication or access control. Its demo view toggle is only a UI demonstration.
- Names, voucher rows, amounts, and links in this copy are fictional or placeholders.
- Do not enter real financial or personal information or connect a production Google Apps Script endpoint.
- The original app in the parent folder remains unchanged and retains its Google Sheets sync. This public copy does not contain its live spreadsheet, form, or Drive IDs.
- The sample Apps Script is only a template; it uses placeholder IDs and does not make uploaded Drive files public.
